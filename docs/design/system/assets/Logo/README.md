# Logo

Nuvola stilizzata con luna a falce parzialmente nascosta, sfumature di azzurro pastello. Usa i file così come sono, senza ricostruirli.

- `app-icon.svg`: icona completa su bianco a tutto campo, vettoriale. Ink: più azzurri pastello, sfondo bianco `#ffffff`.
- `mark.svg`: solo il segno su fondo trasparente, per l'interfaccia. Va appoggiato su bianco o su una tessera bianca; nel tema scuro usa la tessera.
- `app-icon-1024.png`: icona per App Store e sorgente dei ridimensionamenti.
- `apple-touch-icon.png`: 180×180, icona della schermata Home di iPhone.

Nel repository (`docs/design/logo/`) ci sono anche `icon-192.png`, `icon-512.png` e `favicon-32.png` per il manifest della PWA.
