Badge a pillola che dichiara la provenienza o l'origine di un dato: automatico, confermato, stimato o mancante, esito della tolleranza, origine di un insight.

**Cosa fornisci:** il testo, sempre una parola o poche, e la variante.

**Varianti**
- Provenienza di un valore: `badge-auto` (Automatico: arrivato da un segnale, contorno azzurro senza riempimento), `badge-confirmed` (Confermato, azzurro pieno), `badge-estimated` (Stimato, pesca), `badge-missing` (Mancante, bordo punteggiato). Per una notte il femminile: Confermata, Stimata, Mancante.
- Regolarità: `badge-ok` (OK, salvia) e `badge-out` (Fuori, pesca).
- Origine di un insight: `badge-ai` (AI) e `badge-rules` (Regole).
- `badge-forecast` per la previsione, sopra una scheda gialla.

**Regole**
- Ogni badge contiene sempre una parola. Non esiste un badge di solo colore.
- Testo `-ink` della stessa famiglia dello sfondo `-soft`. Altezza 24px, mai oltre due parole.
- Lo stato Stimata si accompagna sempre alla barra tratteggiata e invita a confermare.
